## 【核心算法逻辑伪代码】

原始数据有效 -> 更新时间基线；非法数据 -> 故障锁存；重复时间 -> 不刷新
TF有效 -> 控制；非法 -> 零指令并失败
align -> 先检查当前距离，再检查朝向；距离不合格不能成功
严格加载路线 -> 再进入循环
原始异常 -> 停车/保存/销毁/关闭尽力执行，保留原异常
