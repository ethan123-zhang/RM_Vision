# 小车接线与上电（C8T6 + SN65HVD230 + XHSMCUW50）

> **结论先行（2026-10-21 按实物原理图修正）**
>
> 车上那块「CAN 收发器」是 **SN65HVD230 裸收发器**（板名 `CAN总线通信模块`，
> 原理图只有 U1 + 2 个 10K/120Ω 电阻 + H1/H2 两个排针），**不是串口转 CAN 模块**。
> 它没有 UART，**不能用 USART3 驱动**；正确链路是：
>
> ```
> C8T6 CAN1 (PA11/PA12) -> SN65HVD230 -> CANH/CANL -> XHSMCUW50
> ```
>
> 所以固件已从「USART3 + slcan」改回「片内 CAN1 + 500K」。USART3 留作备用/调试。
> 依据：`CAN收发器原理图.pdf`、`CAN收发器说明书.pdf`（TI SN65HVD230 datasheet）、
> `双驱无刷电机控制器规格书A4pdf.pdf` 6.3/6.4 节。

---

## 0. 整机拓扑

```
Odin1（车上识别/SLAM）
  │ Type-C（只走数据，不走供电）
  ▼
RDK X5  ── 40pin 8/10 (UART1, 3.3V, 115200 8N1) ──►  C8T6 USART1 (PA10/PA9)
  ▲                                                     │
  │ USB3 蓝色口                                          │ CAN1 (PA12/PA11, 500K)
  │                                                     ▼
  └──────────── 10 Hz status / 50 Hz cmd_vel        SN65HVD230
                                                        │ H2: CANH/CANL
                                                        ▼
                                                  XHSMCUW50 双驱控制器
                                                        │
                                                  左/右无刷电机 + 霍尔
DT7 接收机 ── USART2 (PA3, 100000 8E1) ───────────────► C8T6
（手动/急停，s2 打到底 = 硬急停）
```

| 部件 | 作用 | 关键参数 |
| :--- | :--- | :--- |
| Odin1 | 3D 点云 + 图像 + IMU，原生 SLAM/重定位 | USB3，12V/2A |
| RDK X5 | 跑 SLAM/重定位/纯追踪，发 `/cmd_vel` | 5V/5A USB-C，`/dev/ttyS1` |
| C8T6 | 10 ms 仲裁 + 看门狗 + 协议转换 | 5V，USART1/2 + CAN1 |
| SN65HVD230 | 3.3V CAN 收发器，逻辑 ↔ 差分 | 3.3V，板载 120Ω |
| XHSMCUW50 | 双电机速度/角速度闭环 | 15–82V，CAN 500K，ext 0x1314 |
| DT7 | 手动驾驶 + 人肉急停 | 5V，100000 8E1 |

## 1. 电源（22.8V / 6S 电池）

```
电池 22.8V
  │
  ├─ 主保险 40–60 A ── 主开关 ──┬─ XHSMCUW50 BAT+ / BAT-
  │                              │
  │                              ├─ 24V→12V/3A 降压 ── Odin1 12V/2A（航插）
  │                              │
  │                              └─ 24V→5V/6A 降压 ──┬─ RDK X5 USB-C 5V/5A
  │                                                   ├─ C8T6 5V
  │                                                   └─ DT7 接收机 5V
  │
  └─ GND 星形汇流排（电池负极 / 控制器 BAT- / 各降压 GND / C8T6 / X5 / Odin1 / 收发器）
```

要点：

- **控制器标称 15–82 V**，22.8 V 的 6S 电池直接接 `BAT+`/`BAT-`，不要再串降压。
- 主保险按线径选 40–60 A（控制器单路 30 A、双路连续 25 A）；先小后大，别用 100 A。
- **所有逻辑地必须共地**：C8T6、X5、Odin1、DT7、收发器、控制器 J3 的 GND 都回到同一个
  星形点，不要串在电机大电流路径上，否则 CAN 会随机报错。
- X5 用 **5V/5A USB-C**（官方要求），降压模块留 20% 余量（≥6 A），USB-C 线要能过 5 A；
  在 X5 入口并 470–1000 µF 低 ESR 电容，防上电跌落。
- Odin1 用 **12V/2A** 航插，和 Type-C 分开；Type-C 只走数据，不要用带供电的 Hub。
- 控制器 J3 的 `+5V`/`+12V` 引脚**先不接**：手册没写是输入还是输出，不要拿它给
  C8T6/X5 供电；等确认后再考虑。
- 上电前用万用表确认 BAT+/BAT- 极性；反接没有反接保护。

## 2. 信号接线

### 2.1 RDK X5 ↔ C8T6（USART1）

| X5 40pin | 方向 | C8T6 | 说明 |
| :--- | :--- | :--- | :--- |
| 第 6 脚 GND | — | GND | 必须共地 |
| 第 8 脚 UART_TX | → | **PA10** (USART1_RX) | 交叉 |
| 第 10 脚 UART_RX | ← | **PA9** (USART1_TX) | 交叉 |
| — | — | 3.3V | **不接**，两边各自供电 |

- X5 40pin 是 **3.3V 电平**，C8T6 也是 3.3V，直连即可；不要接 5V。
- 115200 8N1；两根信号线尽量短（<20 cm），和电机线分开走。
- 用串口 ISP 烧 C8T6 时，先把这两根线从 PA9/PA10 拔掉，否则 USB-TTL 和 X5 抢脚。

### 2.2 DT7 接收机 ↔ C8T6（USART2）

| 接收机 | C8T6 | 说明 |
| :--- | :--- | :--- |
| 5V | 5V | 接收机供电 |
| GND | GND | 共地 |
| SBUS/DBUS 信号 | **PA3** (USART2_RX) | 100000 8E1 |
| — | PA2 (USART2_TX) | 不用接 |

- s2 打到底 = 硬急停，固件里优先级最高，压过串口。
- 接收机要先和遥控器对频；上电后 `DBUS_Alive()` 才会置位。

### 2.3 C8T6 ↔ SN65HVD230（CAN1）

**这是这次改线的核心。** 收发器 H1 是 4 pin，按原理图逐脚对应：

| H1 | 网络 | 接到 | 说明 |
| :--- | :--- | :--- | :--- |
| 1 | GND | C8T6 GND | 共地 |
| 2 | 3V3 | C8T6 3.3V | **只能 3.3V**，SN65HVD230 不是 5V 器件 |
| 3 | R (接收输出) | **PA11** (CAN_RX) | 收发器 → MCU |
| 4 | D (发送输入) | **PA12** (CAN_TX) | MCU → 收发器 |

> H1 的丝印顺序不一定是 1/2/3/4 从下到上；**以原理图网络为准**，上电前用万用表
> 通断确认：H1-3 应通到 U1 第 4 脚（R），H1-4 应通到 U1 第 1 脚（D）。
> 接反 TX/RX 不会烧，但完全不通。

### 2.4 收发器 ↔ 电机控制器（CAN 总线）

| 收发器 H2 | 控制器 J3 | 说明 |
| :--- | :--- | :--- |
| H2-1 CANH | J3-1 CAN_H | 双绞 |
| H2-2 CANL | J3-2 CAN_L | 双绞 |
| H1-1 GND | J3-6 / J3-7 GND | 共地，抗共模 |

- 用双绞线（CANH/CANL 绞在一起），长度 <1 m；和电机相线分开走。
- 收发器板载 **R2 = 120 Ω** 终端电阻；控制器内部通常也有 120 Ω。
  **断电测量** CANH–CANL：约 60 Ω 最好；约 120 Ω 说明只有一端有终端，在另一端补一个
  120 Ω；约 40 Ω 说明多了一端，拆掉一个。
- 控制器 J3 是 14 pin 航插/端子，按丝印找 1/2；不确定就用万用表对照手册。

### 2.5 控制器 J3 全表（来自规格书 4.3 节）

| Pin | 定义 | 本车怎么接 |
| :--- | :--- | :--- |
| 1 | CAN_H | 收发器 H2-1 |
| 2 | CAN_L | 收发器 H2-2 |
| 3 | +5V | 先不接（方向未知） |
| 4 | RX（SBUS/串口） | 不接 |
| 5 | TX | 不接 |
| 6 | GND | 星形地 |
| 7 | GND | 星形地 |
| 8 | +12V | 先不接 |
| 9 | +12V | 先不接 |
| 10 | GND | 星形地；PowerKey 按钮另一端 |
| 11 | PowerKey | 按钮 → J3-10，按住 ≥1 s 开机 |
| 12 | Break | 急停按钮 → GND（低电平触发） |
| 13 | RS-485 B | 不接 |
| 14 | RS-485 A | 不接 |

**开机**：只接电池控制器不会上电。用自复位按钮把 **J3-11 (PowerKey) 对 J3-10 (GND)
短接约 1 秒**再松开；控制器内部有开机保持。若按了没反应，先查电池电压和 BAT 极性。

**急停**：`Break` 低电平触发。建议接一个常开急停按钮到 GND；不接时保持悬空
（若悬空误报急停，在 Break 与 3.3V 之间加 10 kΩ 上拉）。软件急停（DT7 s2）之外，
这条是硬件最后一道。

### 2.6 电机与霍尔

| 控制器 | 电机 | 说明 |
| :--- | :--- | :--- |
| A / B / C | U / V / W（黄/绿/蓝） | 相线 |
| J1 或 J2 | 霍尔 | 6 pin：1 +5V、2 GND、3 NC、4 Hall_C、5 Hall_B、6 Hall_A |

- 霍尔线颜色通常是红/黑/黄/绿/蓝 = +5V/GND/Hall_A/Hall_B/Hall_C。
  **注意 J1/J2 的 4/5/6 是 C/B/A**，即黄→6、绿→5、蓝→4；不要按 A/B/C 顺序硬插。
- 两个电机分别接控制器的两路；先任意接，装车后如果直行跑偏/转向反，先交换电机
  的两根相线（不要只改软件符号，霍尔相位也要对）。
- 相线和霍尔线远离 CAN 线、USB 线；电机线用 12–14 AWG。

## 3. 上电与自检顺序

1. **断电**接线；万用表查：
   - 电池极性；
   - 5V 降压输出 5.0–5.2 V，12V 降压输出 12.0–12.3 V；
   - H1-2 对 H1-1 为 3.3 V；
   - CANH–CANL 约 60 Ω（断电）。
2. 只上逻辑电（C8T6、X5、Odin1），控制器先不开机：
   - X5 上 `ros2 topic echo /car/status --once`，应看到 `can_ok`（帧已进邮箱）、
     没有 `can_ack`；
   - `link_test` 应 PASS（只证明 X5↔C8T6）。
3. 按 PowerKey 1 s 给控制器开机：
   - 控制器指示灯亮；
   - 约 1 s 内 `/car/status` 出现 **`can_ack`**，说明 CAN 总线真的通了；
   - 若一直 `can_ok` 但没有 `can_ack`，按 §5 排查。
4. **车轮离地**，键盘遥控小速度：
   - 前进/后退/左转/右转方向正确；
   - 松键 ≤300 ms 停；
   - 拔 X5 串口线 0.3 s 内停；
   - DT7 s2 打到底立即停。
5. 落地，`VMAX=0.15` 慢速走一圈；测电机/控制器温度，装散热片后连续跑 5 min
   再摸 MOSFET 温度。

## 4. 散热片

- 规格书写明：**超过 20 A 建议加散热片**。你买的散热片按控制器 160×95×35 mm 的
  功率区贴。
- MOSFET 与散热片之间用导热硅胶垫；如果散热片是铝且会碰到多个管子，确认没有把
  不同电位短在一起（必要时用绝缘垫片）。
- 散热片不要顶到外壳/电池；留出风道。装好后先低速跑 5 min，摸温度，再逐步加速。
- 控制器过流保护是母线 60 A；不要靠它当保险，主保险还是要装。

## 5. 常见错误对照

| 现象 | 先查 |
| :--- | :--- |
| 控制器不上电、灯不亮 | PowerKey 有没有对 GND 短接 1 s；电池电压是否 ≥15 V；BAT 极性 |
| `can_ok` 有、`can_ack` 没有 | CANH/CANL 接反；波特率（PDF 500K，旧工程 250K）；终端电阻；控制器没开机 |
| 一帧 ACK 都没有、`can_ok` 也没有 | PA11/PA12 与 H1-3/4 接反；H1 没供电；CAN 滤波器/固件没烧进去 |
| 电机不动但 CAN 有 ACK | 控制器模式不是 MIX（独立模式会把 angular/speed 当左右轮）；急停 Break 被拉低 |
| 直行跑偏/原地转 | 左右电机接反；相线顺序；MIX/独立模式选错 |
| 转向反 | `bridge_node -p invert_angular:=false`（默认 true 已按 ROS 左正做过一次翻转） |
| 走几步就停、需重启 | 控制器 3–5 s 没收到帧会判信号丢失；查 C8T6 是否在 10 ms 发、X5 卡死时固件是否仍发 0 |
| CAN 随机报错/丢帧 | 共地不良；CANH/CANL 没双绞；电机线干扰；终端电阻不对 |

## 6. 参数速查

| 项 | 值 |
| :--- | :--- |
| X5 40pin UART | 第 8 脚 TX / 第 10 脚 RX，3.3V，`/dev/ttyS1`，115200 8N1 |
| C8T6 USART1 | PA9 TX / PA10 RX，115200 8N1 |
| C8T6 USART2 | PA2 TX / PA3 RX，100000 8E1（DT7） |
| C8T6 CAN1 | PA12 CAN_TX / PA11 CAN_RX，**500 kbit/s** |
| 收发器 | SN65HVD230，3.3V，H1: GND/3V3/R/D，H2: CANH/CANL，板载 120Ω |
| 控制器 CAN | 扩展帧 `0x1314`，8 字节，500 kbit/s，5–20 ms 周期 |
| 混控帧 | `CD AB angular_L angular_H speed_L speed_H crc_L crc_H` |
| 校验 | `0xABCD ^ angular ^ speed`，取低 16 位 |
| ACK 帧 | `speedL speedR voltage crc`，各 2 字节小端，`crc = speedL ^ speedR ^ voltage` |
| 控制器电压 | 15–82 V（22.8 V 6S 直供） |
| 控制器保护 | 欠压 <15 V、过压 >82 V、母线过流 >60 A |
