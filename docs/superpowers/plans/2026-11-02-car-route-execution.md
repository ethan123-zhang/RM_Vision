## 【输入输出定义】

输入为地图、配套 map 路线、动态原始位姿、地图变换和底盘状态；输出为受限速度、状态与实际轨迹记录。

## 【核心算法逻辑伪代码】

验证配套 -> 等待定位与原始数据 -> 范围检查 -> 返回首点 -> 对齐 -> 从头跟踪 -> 进度/距离/朝向联合验收；任一异常停车。

## 【异常与边界条件】

定位停更、缓存重发、地图不匹配、范围超限、通道不明、底盘失联、急停、终点未达均不得报告成功。

## 【验收测试用例】

离线故障注入、ROS 静止数据检查、原位基线、小范围偏移、朝向偏移、急弯/交叉、失联停车、独立终点测量。具体硬件阈值在正式实测前冻结。
