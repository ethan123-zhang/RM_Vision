## 【输入输出定义】

输入：板端实际模式2配置、venue2旧地图、隔离ROS_DOMAIN_ID=94下的 `/odin1/odometry` 与 `/tf`。输出：两轮原始bag、驱动日志、时间推进与静止位姿统计。地图TF与原始odom均检查；不以TF重发频率代替原始数据新鲜度。

## 【核心算法逻辑伪代码】

确认无控制进程/串口占用 → 保持急停与静止 → 有界启动Odin1 → 记录原始odom和TF → 自动停止 → 检查日志明确成功、帧名/数值/时间推进 → 用 inverse(odom←map) × 原始(odom←imu) 计算静止map位姿 → 保存证据。

分析采用bag接收顺序中最新地图TF，与原始odom组合，适用于本次静止观测；不能直接外推为动态时间同步精度评估。地图变换本身数值恒定，故另统计原始odom组合后的位姿波动。
