# 拨弹盘台架：比赛可用性测试（2026-11-18）

> 测试目标在 2026-11-18 改过：**不再做"空盘最高转速"扫描**（T3 取消），只验证比赛真正依赖的四件事——
> 连续送弹不卡、松手停得住（过冲几发）、断电即停、送弹速率够不够点射节奏。
> 取消理由见文末「变更记录」。
>
> 固件：`CHASSIS_BRINGUP_MODE = 5`（拨弹盘台架），C610 ID7 / CAN1，36:1。
> 操作：短按 KEY 切档（10/20/30/50 盘轴 rpm ≈ 3/6/9/15 发/秒），按住转、松开刹车停。
> 说明见 [cboard_chassis/README.md](../../../cboard_chassis/README.md) 的「当前入口：拨弹盘台架」。

## 2. 空载基线（先空盘，再放弹）

每档做一次，用 `0x1F3`（CAN1，25 ms，大端）或直接看 `0x207`，记：

| 项 | 怎么取 |
| :--- | :--- |
| 稳态转子 rpm | 按住 3 s 后的 `0x1F3[4:5]`；盘轴 = ÷36 |
| 启动是否平顺 | 软启动 0.3 s，听/看有没有顿挫 |
| 松手后残速 | 松开瞬间到停住的时间，或看 `0x1F3[4:5]` 归零时间 |

判据：能稳定转到档位转速（±20%）、无明显抖动、松开后 1 s 内停住 → 记"基线可用"。

## 3. 连续送弹（本次核心）

1. 装收集罩/收集袋，**别对着人**。1 档 ≈ 3 发/秒，4 档 ≈ 15 发/秒。
2. 装 N 发弹（建议先 10 发），按住 KEY，看是否连续送完。
3. 每次记录：计划发数、实际送出、是否卡住、卡住时盘是否还在转、是否按 KEY 停、是否需要人工干预。
4. 卡住时**先按 KEY 停**，再断电检查，不要用手去掏。

| 轮次 | 档位 | 计划发数 | 实际送出 | 卡滞（有/无） | 盘是否仍转 | 人工干预 | 备注 |
| :--- | :--- | ---: | ---: | :--- | :--- | :--- | :--- |
| 1 | | | | | | | |
| 2 | | | | | | | |
| 3 | | | | | | | |

判定：同档位连续 3 轮、零卡滞、零人工干预 → 该档位"可用"。
只要出现一次卡滞，记下档位和现象，不要换档掩盖。

## 4. 松手过冲（决定性指标）

做法：按住送弹，数到第 k 发时松开，**数松开后还多送了几发**。

| 轮次 | 档位 | 松开时已送 | 松开后多送 | 停住用时 | 备注 |
| :--- | :--- | ---: | ---: | :--- | :--- |
| 1 | | | | | |
| 2 | | | | | |

为什么关键：每多发一发 = 白烧 10 热量（17 mm）。过冲 ≥2 发就该加刹车力度或降档位。
当前固件松开后是纯 P 反向刹车（`trigger_bench_brake`），残速 <30 转子 rpm 才停发电流。

## 5. 断电即停

1. 按住转着，直接关电池架关机键。
2. 记录：盘是否立刻断电（惯性滑行算"断电"，只要没有驱动力）、ST-Link/分析仪是否掉线。
3. 判据：断电后**没有持续驱动力**；惯性滑行与继续通电要分开描述。

## 变更记录

- **2026-11-18：取消 T3（空盘最高转速）+ 取消手机 240fps 复核。**
  理由：比赛用法是固定送弹速率、按住才送；3V3 冷却优先每发 +10 热量、冷却 24/s，
  持续射速上限 2.4 发/秒（≈盘轴 8 rpm），最高转速与比赛表现无关，反而拉长测试、
  增加台架风险。台架固件同步从"按 N 次选档、脚本跑 7 秒"改成"按住转、松开停"。
  完整规格仍保留在 [2026-11-17-拨弹盘测试与验收.md](../../handoffs/2026-11-17-拨弹盘测试与验收.md)，
  其中 T3 部分仅作历史记录，不再作为本次验收项。
