两个根因：

1. **回起点"边走边转"的转弯半径小于到位容差。** `w=1.5*heading_err`（上限`return_w_max`）+ 实测角速度增益≈1.7×，配`return_v_max=0.06`得到**转弯半径仅0.14 m < `start_pos_tol_m`=0.10+**，纯追踪对着一个点会退化成像"绕点打圈"，最后靠轨迹偶然穿过容差圈才"到位"，此时朝向完全不对。
2. **位姿传感器偏离转心 ≈0.25 m，"位置在起点"和"朝向对齐"两个判据物理上互斥。** 由两次实测反推：纯转77°→位姿扫0.316 m；转140°（尝试1的实际需求）→扫0.47 m。也就是说只要起始朝向差大，任何"原地转+位置容差"的判据都必然触发失败。**这是设计缺陷，不是参数问题。**

- **符号正确**：正角速度指令→左转（CCW，正yaw），正反两发75单位幅度对称（+12.42°/−12.75°，差2.6%）。`invert_angular`默认true的设置成立，不需要改。
