## 本次得到的结论

1. **延长窗口是必要的。** 原2秒末段欠速不能直接作为最终稳态误差；8秒记录显示转速仍在逐步收敛。没有依据据此直接提高电流上限。
2. **Ki对照改善了平均收敛。** Ki=0.004首轮选入速度段末2秒平均误差约0.10%～0.69%；3号独立补测为1.03%/0.19%。反转积分换向从约1.1～1.2秒缩短到0.42～0.55秒。上述是采样窗口结果，不是所有工况或未来复测的保证。
3. **积分历史影响正反瞬态。** 零速段保留积分；反转初期先消除正向积分。不能把全部正反差异都判为机械方向差异。
4. **平均准确不等于瞬时稳定。** 约70Hz的第7阶角度相关纹波仍在，1号尤清晰；2/4号另有较慢的降速过程。不能仅凭诊断帧曲线平滑或平均误差小宣布调好。
5. **原始反馈比低频诊断更适合判断波动。** 0x1F2约38.5Hz，不能辨认70Hz纹波；轮速约1kHz、指令约500Hz。分析阶段边界需留裕量，避开切零制动。编码器角度与电调rpm同源，不构成独立测速验证。
6. **异常记录与正常对照必须并存。** Ki首轮2号有7576帧指令命中1500、约10.4秒反馈空档和反馈不可用取消；正常选入段没有饱和。更换CAN线后的成功测试不等于长期可靠性已验收，也不能反推前轮全部下降都由线材造成。
7. **基础功能已通。** 四轮完整序列、KEY取消已有证据；3号补测确认末尾零速及退出后零电流。掉线有一次实际取消记录，超速保护没有专项实测。
