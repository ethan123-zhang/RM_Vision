## 400/600单变量对比（诊断用途，非验收）

### 口径

方法冻结在[analyze400compare.py](analyze400compare.py)内，两种转速完全相同：

- 数据源：400rpm两轮为本目录两轮采集；600rpm两轮为[600rpm两轮验收](../stage1-acceptance/README.md)的原始采集（同一Ki=0.004固件、模式3、8/1/8/1秒，唯一差异是目标600）。600侧只复用其原始帧，不重算或改动其验收结果。
- 降速事件：对**方向统一符号后的原始rpm**做20ms向后移动平均；低于目标的90%（400为360rpm，600为540rpm）、持续≥50ms、间隔<100ms合并；排除每段开始1秒和结束前0.2秒。每个事件记录开始/最低点/恢复、深度、恢复时间、相邻Δt、相邻Δrev（编码器角度展开，8192计数/转；同时用rpm积分复核）。
- 降速簇：事件起点间隔≤0.8秒合并为一簇，用簇起点计算周期与Δrev——这是主判据，因为簇内还有2～3个次级凹陷。
- 频谱：末2秒原始rpm均匀重采样2ms、线性去趋势、Hann窗，2～100Hz峰值；同时用转子角度做1～12阶角度锁定正余弦回归，报告第7阶幅值。角度来自反馈字节0..1、模8192，展开时相邻差按±4096回绕处理，不跨空档插值。
- 低速谱峰另用整段20ms均值做0.1～10Hz分析，但因窗口与簇内多峰影响，峰值在0.44～2.8Hz间不稳定，仅作参考，不作判据。

- 这5段都出现在**段开始**：目标切换后命令先到Kp×目标（400侧约800），转子角度几乎不动、实测电流升到约900～1200协议单位后突然脱开并加速——是典型的起转粘滞/静摩擦脱开，不是运动中掉线，也不是稳态降速本身。1号在400侧、以及600rpm的两轮采集里都没有检出≥60ms的同类区间（600侧Kp×600≈1200，起转更快，可能只是低于检测门限；1号在400侧未出现说明其静摩擦更低）。
- 该观察只支持“2/4号机械阻力（静摩擦/卡滞）高于1号”的假设，**不能**直接证明它就是稳态15转/簇降速的原因，也没有区分电机-减速箱内部与轮组侧。下一项实验据此设计。

## 不能下的结论

- 不能写“降到400rpm解决了问题”或“400rpm通过验收”：2/4的相对波动反而更大，且400rpm序列不是第一阶段验收序列。
- 不能由本报告认定机械/电调/控制环某一个为根因；转动相关证据只支持假设，且降速事件在角度上并未表现出可冻结的单一锁定关系，本报告不据此给出根因结论。
- 不得在未重新验收的情况下把400rpm参数或结论用于600rpm验收；600rpm标准与两轮结论保持不变。
- 起转粘滞扫描是探索性检查，阈值未经独立复核，不能当作故障判定或保护验收。

## 下一步单变量实验（建议，待用户确认后执行）

**目标**：区分约15转/簇的周期降速是“轮组侧（轮毂/全向轮/紧固件/轴承）”还是“电机-减速箱-电调/供电侧”。

- 假设：若降速簇跟随轮组走，则属于轮组侧机械问题；若固定在原电机/减速箱/位置，则属于电机-减速箱或电气侧。起转粘滞差异也作为辅助判据。
- 唯一变化：把**1号（参考，无降速簇）与2号的完整轮组（轮毂+全向轮+紧固件）互换安装**；固件、模式3、400rpm、Kp=2/Ki=0.004、限流±1500、8/1/8/1秒、KEY流程、采集脚本全部不变；4号保持原样作第二参照。无需烧写。
- 采集与指标（冻结同口径）：架空、同一采集脚本；每轮1→2→4各一次18秒，至少两轮；比较两轮末2秒均值/标准差、降速簇Δt与Δrev、事件深度/恢复、起转粘滞时长与电流；并保留原始曲线与事件CSV。
- 判定：若2号位置恢复正常、1号位置出现降速簇（异常跟着轮组走）→ 轮组侧；若降速簇仍固定在原2号电机/减速箱/位置 → 电机-减速箱或电气侧，再做“单换电机/减速箱（同备件、标记电缆）”对照。起转粘滞也一并复核。
- 回退：换回原轮组并拍照/记录编号；不改固件、不重烧。若互换后现象消失但无法确认归属，恢复原状并另开窗口重复，不合并两次结论。
- 备选（需烧写，优先级低）：加一个±300rpm转速点验证簇Δrev是否仍约15转；只在轮组对照不可行时启用。
