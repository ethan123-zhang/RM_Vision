# 4号轮固定电流开环诊断

日期：2026-10-29。用户报告 4号轮"有问题"，需要给 4号电机施加**恒定电流（开环）**，观察每转一次的顿挫是否仍然出现。本实验只用于区分现象来源，不作验收，也不改速度环参数。

## 目的与假设

- 目的：把速度环从回路中拿掉，只让 C620 内部电流环跟踪一个固定电流指令，观察 4号轮（CAN ID 4）在恒定转矩下的转速波动/顿挫。
- 假设 A（机械/电机侧）：若恒定电流下仍出现与转子角度或每转位置相关的规律性顿挫 → 与速度环无关，指向轮组/减速箱/电机换向等机械或本体原因。
- 假设 B（控制侧）：若固定电流下顿挫消失或形态明显改变 → 现象至少部分来自速度环与纹波的交互，需要回到控制侧继续定位。
- 开环的终端转速由「电流产生的转矩 = 摩擦/损耗」平衡决定，不能像速度模式那样直接指定 400rpm；因此用 4 档电流（KEY 次数）试探，记录实际稳态转速。

## 唯一变化（相对当前 400rpm 速度模式构建）

- `cboard_chassis` 新增编译期模式 `CHASSIS_BRINGUP_MODE_OPEN_LOOP = 4`，并临时把默认模式改为 4。
- 新模式固定驱动 **CAN ID 4**，KEY 按 N 次（1..4）选择电流档：

| KEY 次数 | 电流指令（C620 单位） | 说明 |
| ---: | ---: | --- |
| 1 | 250 | 最低档，先试是否起转 |
| 2 | 400 | 约等于润滑前 400rpm 的保持电流 |
| 3 | 550 | 中档 |
| 4 | 700 | 最高档（本模式硬上限 800） |

- 停手 3 秒后开始输出，持续 **12 秒**自动归零释放；运行中再按一次 KEY 立即取消。
- 保护：反馈掉线取消（0x1F2 状态 2）；绝对转速 >900rpm 取消（状态 3）；12 秒超时正常释放。
- **没有**改官方解算、PID、限流、方向表；速度模式的 400rpm/Kp=2/Ki=0.004 参数原样保留，只是本模式不使用速度环。

## 上板操作

1. 架空底盘、4号轮离地、轮边无杂物线缆，可立即断电；手不碰轮子。
2. 用户用 Keil 界面 F8 烧写本构建（代理不碰界面、不用命令行烧写）。
3. 上电后板子处于模式 4：零电流等待。
4. 采集窗口先开，再按 KEY：按 N 次 → 停手 3 秒 → 4号轮恒定电流输出 12 秒 → 自动释放。
   想换档就等释放后再按新的次数；想中止随时再按一次 KEY。
5. 0x1F2 诊断字段：`[0]`=CAN ID（固定 4）；`[1]`=0 空闲/1 运行/2 反馈不可用/3 超速；`[2:3]`=电流指令；`[4:5]`=实测 rpm；`[6:7]`=实测电流反馈（均为大端）。

## 采集与分析口径（采集后执行）

- 原始 0x204（4号反馈：角度/转速/电流/温度）、0x200 指令、0x1F2 诊断按 device_us 归零。
- 去掉每次输出的起转瞬态（前 2 秒），只分析稳态段；报告实际转速、电流反馈均值/波动、温度。
- 顿挫检测沿用已冻结的降速事件口径（20ms 移动平均、相对下降 10%、≥50ms、间隔 <100ms 合并），同时给出**角度锁定**检查：把事件时刻对应到转子角度（模 8192），看是否集中在固定角度；并统计每转/每输出圈的事件数。
- 与 400rpm 速度闭环下 4号的数据对比：事件周期（Δt/Δrev）、深度、恢复、电流补偿。
- 原始文件、摘要、事件 CSV、曲线单独保存在本目录；不做 600rpm 验收结论。

## 安全与回退

- 本模式只驱动 ID 4，其余三轮始终零电流；有 12 秒超时、900rpm 超速、反馈掉线三重保护；用户可随时按 KEY 取消或断电。
- 回退：把 `CHASSIS_BRINGUP_MODE` 改回 `CHASSIS_BRINGUP_MODE_SPEED_TEST`（3），主机测试 + Keil 重新编译，由用户 F8 烧写；不回滚其他工程配置。
- 若开环时轮子完全不起转（电流顶不过静摩擦），属预期可能结果：先试更高档，仍不动则记录为「开环未能起转」，不再提高电流（本模式硬上限 800）。
