# 决策：RDK X5 person 模型定稿 576 输入

- 日期：2026-10-18
- 状态：已采纳
- 相关：`x5_yolo/`

## 背景

单类 person YOLOv8n 已在 X5 上跑通 640 / 576 / 512 三档。目标 100~150 FPS，
同时自瞄不能丢太多小目标精度。

## 实测

| 输入 | 最佳配置 | FPS | person AP@0.5 |
|---|---|---|---|
| 640 | pipeline3 + C++ post | 87.2 | **0.7244** |
| **576** | **pipeline3 + C++ post** | **104.1** | **0.7178** |
| 512 | pipeline + C++ post | 135.3 | 0.5572 |

AP 为 COCO val 200 张、person 类；640/576/512 各自输入尺寸评测。

## 结论

选 **576**。相对 640 只掉 0.0066（0.9%），帧率从 87 提到 104，进入 100+；
512 虽 135 FPS，但小目标 AP 掉 23%，不适合自瞄。

## 影响

- 交付模型：`yolov8n_person1_576_bayese_576x576_nv12.bin`（3.5 MB）。
- 板端命令：`--size 576 --pipeline3 --cv-threads 1 --cpost`。
- 640 / 512 模型保留，作为精度优先 / 速度优先备选。

## 复审条件

- 若相机分辨率或目标尺寸变化导致 576 小目标仍不够：回 640，并用零拷贝输出优化。
- 若需要 150 FPS：512 或进一步降输入，并接受精度代价。
