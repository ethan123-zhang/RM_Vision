# 小车路线复现：底盘标定与首次实车回放收尾

日期：2026-11-03 21:24 – 2026-11-04（整理落盘）。本文件优先于 `2026-11-03-car-slam-lap-closeout.md`。

本次会话从"线速度标定"做到"跟踪器首次上车回放"，两次回放都被安全门判停，但每次判停都换来了确定的结论；结束时按用户要求关机。

## 本轮做了什么

1. **线速度初标定（三发，硬件实测）**：100 单位（名义 0.08 m/s）脉冲 3 s，实测位移 0.28139 / 0.26680 / 0.28376 m，稳态 0.09597 / 0.08471 / 0.09705 m/s，偏航 +0.442 / −0.033 / −0.116°，横向 ≤4 mm。run1 与 run3 相差 1.1%，run2 是低值离群（t=0.65 s 处有一次 5 mm 位置回退），最大偏离中位数 11.7% → **不达 ≤10% 的冻结门槛，记为初标定**。共识：100 单位 ≈ 0.095 m/s ⇒ `mps_at_max` 建议 0.8 → 0.95（当前 0.8 会让指令 0.08 m/s 实际跑到 ≈0.096 m/s，快 20%）。
2. **角速度初标定（5 发，1 发被拒）**：+0.06/30u → 窗口内 0.021 rad/s；±0.15/75u → +12.42° / −12.75°（对称 2.6%，**符号正确**）；+0.25/125u → 11.66°；+0.30/150u 那发第 0.284 s 因 `can_ack` 瞬时丢失（status 119→103）被安全门中止写零，约 1 分钟后复查自行恢复。结论：`radps_at_max` 保持 2.0（1 秒指令口径吻合）、停发后滑转 4.4–4.9°、带宽内存在 18–30 单位死区、**Odin1 距转心 0.19–0.22 m**。
3. **跟踪器首次实车回放（用户选"让车自己回起点"）**：两次尝试，均安全停车。尝试1 回起点到位（0.09 m）但起始对齐被判"漂离"；实际轨迹显示车**绕起点画半径 0.14 m 的圈**、到位时朝向差 162°。尝试2 再次被判停，实测**原地转 77° 期间位姿点扫过 0.316 m**。
4. **两处代码修复 + 测试 + 部署**：`follow_path.py` 新增 `RETURN_MIN_RADIUS_M=0.40`（回起点行驶中按 `w ≤ v/R` 限幅）与 `START_ALIGN_DRIFT_SLACK_M=0.15`（对齐漂移判据留力臂余量），新增 3 个测试；本地 158 项全过；板端 `colcon build` 后 install 与本地同哈希 `c16ad784…`，部署副本 `~/car-deployments/replay-fix-20261103-220116`。
5. **关机**：停驱动与桥接、确认 `/dev/ttyS1` 空闲、`sync` 后 `sudo shutdown -h now`，SSH 随即断开。

## 【输入输出定义】

输入：已绑定 map 的示教路线、新鲜原始 odom、地图 TF、底盘状态、实测速度比例。输出：有界 `cmd_vel` 与任务结果；本轮只产出标定数据与受限脉冲，尚无一次完整的实车整圈回放。

## 【核心算法逻辑伪代码】

```text
开机盘点 → 起定位并核对与起点的位姿差
→ 选起点策略（A 降级 / B 先转正再补位）
→ 安全门全绿 → 受限回放（max_time_s 兜底）
→ 失败停车后取实际轨迹定位根因 → 修控制器 → 重新部署
```

## 【异常与边界条件】

- 关机命令已下发不等于已物理断电；远程探测经本机代理，不能作为断电证据。
- 角速度标定的"1 秒口径吻合"只说明该工作点可用，稳定段仍是名义值的 1.5–1.9 倍，长弯会过转。
- 力臂 0.25 m 是单车身实测；换传感器/换支架必须重测。
- 两次回放都在 `return`/`align_start` 阶段停止，跟踪器主循环（`run`/`track_align`/终点对齐）在实车上**仍未验证**。
- 单次脉冲成功不代表长期可靠性；标定结论只覆盖低速、单一占空比。
